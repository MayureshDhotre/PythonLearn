1. Variables Basics
Variables
name = "Alice" age = 25 height = 5.8 is_student = True
Variables store values.
Multiple Assignment
x, y = 10, 20
Assign multiple values at once.
Type
type(age)
Returns the data type of a variable.
2. Data Types Core
String
"Hello"
Text data.
Integer
42
Whole numbers.
Float
3.14
Decimal numbers.
Boolean
True False
True or false values.
None
value = None
Represents no value.
List
[1, 2, 3]
Ordered, mutable collection.
Tuple
(1, 2, 3)
Ordered, immutable collection.
Set
{1, 2, 3}
Collection of unique values.
Dictionary
{"name": "Alice"}
Key-value collection.
3. Input & Output
Input
name = input("Enter name: ") age = int(input("Enter age: "))
Gets input from the user.
Print
print("Hello", name)
Displays output.
F-string
print(f"Hello {name}")
Convenient string formatting.
4. Operators
Arithmetic
+ - * / // % **
Addition, subtraction, multiplication, division, floor division, remainder and power.
Comparison
== != > < >= <=
Compare values.
Logical
and or not
Combine or invert conditions.
Assignment
= += -= *= /=
Assign or update values.
5. Strings
Create
text = "Python"
Create a string.
Length
len(text)
Returns string length.
Case
text.lower() text.upper()
Convert case.
Strip
text.strip()
Removes leading/trailing whitespace.
Replace
text.replace("Py", "My")
Replaces text.
Split
text.split()
Splits a string into a list.
Slicing
text[0] text[-1] text[1:4]
Access characters or ranges.
6. Lists
Create
numbers = [1, 2, 3]
Create an ordered collection.
Add
numbers.append(4) numbers.insert(1, 10)
Add items to a list.
Remove
numbers.remove(2) numbers.pop()
Remove items.
Sort
numbers.sort() numbers.reverse()
Sort or reverse a list.
Indexing
numbers[0] numbers[-1] numbers[1:3]
Access list elements.
7. Dictionaries
Create
student = { "name": "Alice", "age": 20 }
Store key-value pairs.
Access
student["name"] student.get("age")
Access dictionary values.
Add / Update
student["grade"] = "A"
Add or update a value.
Loop
for key, value in student.items(): print(key, value)
Loop through key-value pairs.
8. Sets
Create
nums = {1, 2, 3}
Create a set of unique values.
Add / Remove
nums.add(4) nums.remove(2)
Add or remove elements.
Union
a | b
Combines two sets.
Intersection
a & b
Returns common elements.
Difference
a - b
Elements only in the first set.
9. Conditions
If / Elif / Else
age = 18 if age >= 18: print("Adult") elif age >= 13: print("Teen") else: print("Child")
Execute code based on conditions.
10. Loops
For Loop
for i in range(5): print(i)
Repeat code for each item.
While Loop
count = 0 while count < 5: print(count) count += 1
Repeat while a condition is true.
Break
if i == 5: break
Exit a loop.
Continue
if i % 2 == 0: continue
Skip the current iteration.
11. Functions
Function
def greet(name): return f"Hello {name}" print(greet("Alice"))
Create reusable code.
Default Argument
def power(base, exponent=2): return base ** exponent
Arguments can have default values.
Lambda
square = lambda x: x * x
Small anonymous function.
12. Comprehensions
List
squares = [x*x for x in range(10)] evens = [ x for x in range(20) if x % 2 == 0 ]
Compact way to create lists.
Dictionary
squares = { x: x*x for x in range(5) }
Compact way to create dictionaries.
13. Exception Handling
Try / Except
try: x = 10 / 0 except ZeroDivisionError: print("Cannot divide by zero") finally: print("Done")
Handle runtime errors safely.
14. File Handling
Write
with open("file.txt", "w") as f: f.write("Hello")
Write data to a file.
Read
with open("file.txt", "r") as f: content = f.read()
Read file contents.
15. Classes & Objects
Class
class Person: def __init__(self, name): self.name = name def greet(self): print(f"Hello, I'm {self.name}") p = Person("Alice") p.greet()
Create classes and objects using OOP.
Inheritance
class Student(Person): def study(self): print("Studying") s = Student("Bob") s.greet() s.study()
A class can inherit functionality from another class.
16. Modules & Imports
Import
import math math.sqrt(16) math.pi
Use functionality from another module.
Specific Function
from random import randint print(randint(1, 10))
Import a specific function.
17. Common Built-in Functions
Functions
len() sum() min() max() sorted() range() enumerate() zip() map() filter() abs() round() any() all() type()
Frequently used Python built-in functions.
18. Enumerate & Zip
Enumerate
names = ["Alice", "Bob"] for i, name in enumerate(names): print(i, name)
Get index and value while looping.
Zip
names = ["Alice", "Bob"] ages = [20, 25] for name, age in zip(names, ages): print(name, age)
Loop through multiple sequences together.
19. Range
Examples
range(5) range(1, 6) range(0, 10, 2)
range(5) → 0–4
range(1, 6) → 1–5
range(0, 10, 2) → 0, 2, 4, 6, 8
20. Useful Python Patterns
Swap
a, b = b, a
Swap two values.
Ternary
status = "Adult" if age >= 18 else "Minor"
One-line conditional expression.
Membership
if "apple" in fruits: print("Found")
Check whether an item exists.
Reverse
reversed_list = numbers[::-1]
Reverse a sequence.
Remove Duplicates
unique = list(set(numbers))
Remove duplicate values.
21. Virtual Environment & pip
Create
python -m venv venv
Create a virtual environment.
Windows
venv\Scripts\activate
Activate on Windows.
Linux / macOS
source venv/bin/activate
Activate on Linux or macOS.
Install
pip install package_name
Install a Python package.
Requirements
pip freeze > requirements.txt pip install -r requirements.txt
Save and install dependencies.
22. Common Python Libraries
Libraries
math random datetime os sys json re pathlib requests numpy pandas matplotlib scikit-learn
Math, random numbers, dates, OS operations, JSON, regular expressions, file paths, HTTP, numerical computing, data analysis, visualization and machine learning.
23. Main Program
Entry Point
def main(): print("Hello") if __name__ == "__main__": main()
Common pattern for running a Python script directly.
24. Debugging
Inspect
print(variable) print(type(variable)) print(dir(variable))
Inspect values, types and available attributes.
Assert
assert age >= 0 assert x == 10, "x must be 10"
Check assumptions while developing.
25. Important Python Keywords
Keywords
if elif else for while break continue pass def return class import from as try except finally raise with lambda yield in is and or not True False None
Important reserved words used in Python.
